연말정산 미리보기 D-day

홈택스 연말정산 미리보기 서비스 개시일까지 D-day를 알려드립니다. 매년 11월 중순 개시되며, 1~9월 카드 사용액을 기반으로 예상 환급세액을 미리 시뮬레이션할 수 있습니다.

미리보기 전 준비 체크리스트

  • 홈택스 로그인 — 공동인증서 또는 간편인증(카카오·네이버·PASS 등)으로 미리 로그인 확인
    연말정산 미리보기는 홈택스(hometax.go.kr) 로그인 후 이용 가능합니다.
  • 신용·체크카드 사용 내역 확인 — 1~9월 카드 사용액은 미리보기 서비스 내 자동 반영
    10~12월분은 별도로 예상 사용액을 직접 입력합니다.
  • 부양가족 공제 요건 확인 — 연간 소득 100만원 이하(근로소득만 있는 경우 500만원 이하) 조건
    부모님·배우자·자녀 공제 가능 여부를 미리 확인하세요.
  • 의료비 영수증 수집 — 병원비·안경·보청기 등 국세청 미집계 항목 별도 준비
    보험사에서 수령한 보험금에 해당하는 의료비는 공제 대상에서 제외됩니다.
  • 교육비·기부금 영수증 준비 — 국세청 자료에 없는 경우 별도 제출 필요
    종교단체 기부금은 기부금 영수증을 직접 수집해야 합니다.
  • 주택 관련 공제 확인 — 무주택 세대주의 월세액 공제, 주택청약 공제 등
    월세 공제는 총급여 8,000만원 이하 무주택 근로자가 대상입니다.

홈택스 연말정산 미리보기 이용 방법

  1. 홈택스(hometax.go.kr) 로그인
  2. 상단 메뉴 [장려금·연말정산·전자기부금] 클릭
  3. [편리한 연말정산] → [연말정산 미리보기] 선택
  4. 1~9월 신용카드 사용액 자동 불러오기 확인
  5. 10~12월 예상 사용액 입력 후 예상 환급세액 계산
  6. 절세 전략 시뮬레이션 (기부·의료비·연금 추가 납입 등)
