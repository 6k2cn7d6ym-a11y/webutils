## 3. 반응형 규격

### breakpoint 기준

| 디바이스 | 너비 | 슬롯 배치 | 슬롯 수 |
|---|---|---|---|
| 모바일 | < 320px | 결과 하단만 | 1 |
| 모바일 | 320px ~ 767px | 결과 하단만 | 1 |
| 태블릿 | 768px ~ 1023px | 결과 하단 + 본문 하단 | 2 |
| 데스크톱 | ≥ 1024px | 결과 하단 + 본문 하단 | 2 |

### 모바일 우선 전략
- 기본값: 1개 슬롯 (결과 하단), 본문 하단 슬롯 `display: none`
- `@media (min-width: 768px)`: 본문 하단 슬롯 `display: block` (CSS만)

## 4. 슬롯 컨테이너 CSS 스펙

### 기본 컨테이너 스타일

```css
.ad-slot {
  min-height: 250px; /* CLS 방지: 광고 미로드 시 예약 공간 */
  max-width: 100%;
  width: 100%;
  margin: 2rem auto;
  padding: 1rem;
  border-radius: 4px;
  background-color: transparent; /* [달리 수정: #f9f9f9 하드코딩 → transparent] */
  text-align: center;
}

.ad-slot-label {
  display: block;
  font-size: 0.75rem;
  color: #999;
  margin-bottom: 0.5rem;
  text-align: center;
  font-weight: 600;
  letter-spacing: 0.05em;
}
```

### 라벨 규격

```html
<div class="ad-slot">
  <div class="ad-slot-label">광고</div>
  <ins class="adsbygoogle" ...></ins>
</div>
```

- **라벨 텍스트**: "광고" (명확한 구분)
- **크기**: 0.75rem
- **색상**: #999
- **위치**: 슬롯 상단, 중앙 정렬
- **폰트 무게**: 600

### 반응형 컨테이너

```css
/* 모바일 기본 */
.ad-slot {
  max-width: 100%;
  margin: 1.5rem auto;
  padding: 0.75rem;
  min-height: 250px;
}

/* 본문 하단 슬롯: CSS 기본값으로 hidden — inline style 개입 없음 */
/* inline style="display:none" 사용 시 media query(10)가 inline(1000)에 패배 → 광고 미노출 */
.ad-slot-bottom { display: none; }

/* 태블릿 이상: 본문 하단 슬롯 표시 */
@media (min-width: 768px) {
  .ad-slot {
    max-width: 90%;
    margin: 2rem auto;
    padding: 1rem;
  }

  .ad-slot-bottom { display: block; }
}
```

> ⚠️ 이 태그 없이 하단 슬롯 스니펫만 삽입하면 광고 미로드. 반드시 `<head>` 안에 포함.


### ③ 본문 하단 슬롯 (태블릿·데스크톱 · CSS로만 제어)

```html
<!-- 기본 hidden은 CSS .ad-slot-bottom { display: none } 으로 처리 — inline style 제거 -->
<div class="ad-slot ad-slot-bottom" id="ad-slot-bottom">
  <div class="ad-slot-label">광고</div>
  <ins class="adsbygoogle"
       style="display:block"
       data-ad-client="ca-pub-9477150496807643"
       data-ad-slot="[유틸별 슬롯 ID — AdSense 콘솔에서 개별 생성 후 매핑]"
       data-ad-format="auto"
       data-full-width-responsive="true"></ins>
</div>
<script>(adsbygoogle = window.adsbygoogle || []).push({});</script>
```

> **CSS 우선순위 주의**: `.ad-slot-bottom { display: none }` 은 반드시 CSS로만 선언. inline `style="display:none"` 사용 시 우선순위 1000으로 media query(10)를 이겨 광고 미노출 사고 발생. inline 개입 금지. [달리 수정: JS 제어 → CSS media query 교체 · CSS 우선순위 결함 해소]

## 6. Auto ads vs 수동 슬롯 권고

| 방식 | 장점 | 단점 | 권고 |
|---|---|---|---|
| **Auto ads** | Google이 자동 최적화, 관리 최소 | 배치 통제 불가, UX 변동성 | **비권고** ❌ |
| **수동 슬롯** | 배치 통제, UX 일관성, 정책 준수 명확 | 직접 관리 필요 | **권고** ✅ |

**결론**: webutils는 **수동 슬롯 배치** 전략. 유틸마다 AdSense 콘솔에서 슬롯 ID 개별 생성 후 `data-ad-slot`에 매핑.
