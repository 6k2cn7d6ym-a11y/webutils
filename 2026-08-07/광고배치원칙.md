## 2. 광고 밀도 상한

**유틸 1건당 최대 2개 슬롯**

| 경우 | 규격 |
|---|---|
| 모바일 (< 768px) | 1개 슬롯 (결과 하단만) |
| 태블릿 (768px ~ 1024px) | 2개 슬롯 (결과 하단 + 본문 하단) |
| 데스크톱 (≥ 1024px) | 2개 슬롯 (결과 하단 + 사이드바 또는 본문 하단) |

**필수**: 2개 이상 슬롯 삽입 금지 (UX 저해, AdSense 정책 위반 위험)

## 4. 슬롯 컨테이너 CSS 스펙

```css
.ad-slot {
  min-height: 250px; /* CLS 방지: 광고 미로드 시 예약 공간 */

  padding: 1rem;

  text-align: center;

.ad-slot-label {
  display: block;
  font-size: 0.75rem;
  color: #999;
  margin-bottom: 0.5rem;
  text-align: center;
  font-weight: 600;
  letter-spacing: 0.05em;
```

### 라벨 규격

```html
<div class="ad-slot">
  <div class="ad-slot-label">광고</div>
  <ins class="adsbygoogle" ...></ins>
</div>
```

- **라벨 텍스트**: "광고" (명확한 구분)
- **크기**: 0.75rem (작지만 인지 가능)
- **색상**: #999 (회색, 저조도)
- **위치**: 슬롯 상단, 중앙 정렬
- **폰트 무게**: 600 (약간의 강조)

### 반응형 컨테이너

```css
/* 모바일 (< 768px) */
.ad-slot {
  max-width: 100%;
  margin: 1.5rem auto;
  padding: 0.75rem;
  min-height: 250px;
}

/* 태블릿 이상 (≥ 768px) */
@media (min-width: 768px) {
  .ad-slot {
    max-width: 90%;
    margin: 2rem auto;
    padding: 1rem;
  }
}

/* 데스크톱 사이드바 (≥ 1024px) */
@media (min-width: 1024px) {
  .ad-slot-sidebar {
    max-width: 300px;
    min-height: 600px; /* 수직 광고 형식 대비 */
  }
}
```

## 6. Auto ads vs 수동 슬롯 권고

| 방식 | 장점 | 단점 | 권고 |
|---|---|---|---|
| **Auto ads** | Google이 자동 최적화, 관리 최소 | 배치 통제 불가, UX 변동성 | **비권고** ❌ |
| **수동 슬롯** (권고) | 배치 통제, UX 일관성, 정책 준수 명확 | 직접 관리 필요 | **권고** ✅ |

**결론**: webutils는 **수동 슬롯 배치** 전략 사용. 각 유틸 페이지에 명시적 슬롯 배치 → UX 보증 + AdSense 정책 준수.
