## 2. AdSense 심사관 첫 인상 — 이슈 3건

### 이슈 1 (고) — meta description·og tags 구식

현행 (`index.html` line 7):
> "장례식 조의금·부동산 취득세·중개수수료·에어컨·원룸 전기요금·색상 팔레트 등…"

사이트가 D-day·기한 계산기로 빠르게 확장됐으나 메타 텍스트는 초기 계산기 중심 그대로. AdSense 심사관이 메타만 읽으면 현재 콘텐츠의 절반을 인지 못 함.

**달리 권고 수정안:**
```
생활 계산기부터 출생신고·상속포기·임대차·장기요양 기한 D-day 계산기까지,
실생활에서 자주 찾는 생활 유틸을 모아 무료로 제공합니다.
```

og:description도 동일 기조로 갱신 필요.

### 이슈 2 (고) — hero lede 구식

현행 (`index.html` line 210):
> "장례식 조의금, 부동산 취득세·중개수수료, 에어컨·원룸 전기요금 등 검색해도 답이 애매한 계산을…"

D-day 계산기·기한 안내 카테고리가 현재 카드 27개 중 10개 이상을 차지하는데 lede에 전혀 언급 없음. 심사관이 실제 페이지를 스크롤하면 D-day 유틸들이 눈에 띄지만, 첫 문단 텍스트가 인지 불일치 유발.

**달리 권고 수정안:**
```
부동산·취득세·중개수수료부터, 출생신고·임대차 계약 만료·상속포기 등
기한이 중요한 D-day 계산기까지 — 검색해도 애매한 계산을 바로 확인할 수 있게 정리했습니다.
```

### 이슈 3 (저) — 구 유틸 카드 색상: 팔레트 미정합

현행 `index.html` — 구 유틸군(장례·취득세·중개수수료·에어컨·원룸 등) `card-accent` 색상은 11축 팔레트 미적용 상태. 예:
- funeral-condolence: `#2D4A6B` (브랜드 네이비 = 팔레트 외)
- acquisition-tax: `#2C5F3E` (다크 그린 = 팔레트 외)
- ac-electricity: `#4A5380` (스틸 블루 = 팔레트 외)

AdSense 심사관은 색상 일관성을 직접 체크하지 않으나, 카드 그리드 전체가 맥락 없이 다양한 색이면 "관리되지 않는 사이트" 인상 줄 수 있음.

**달리 판단**: 이슈 1·2 먼저. 구 유틸 색상 정합은 카드 27개 전면 수정 → 개발팀 개입 필요 → 이번 사이클 즉시 처리 대상 아님. 예약 이슈로 등록하고 다음 사이클 마이클 상신.

- meta description(line 7) · og:description(line 10) · twitter:description(line 16) 3곳 구식 문안 실측 확인 (달리 지적 정확).

- D-day 유틸 카운트: 27카드 중 10개 실측 (달리 "10개 이상" 정확).

### 판정 1 — meta·og·twitter·JSON-LD 갱신 (채택 · 문안 조정)

**최종 문안:**
```
생활 계산기부터 출생신고·상속포기·임대차·장기요양 기한 D-day 계산기까지,
실생활에서 자주 찾는 생활 유틸을 로그인 없이 무료로 제공합니다.
```

조정 근거:
- 달리 안 골격 유지.
- "로그인 없이" 삽입 — AdSense 심사관 실사용성 어필 강화 (로그인 벽 없는 무료 유틸 명시).
- 반영 위치 4곳: `index.html` line 7 (meta description) · line 10 (og:description) · line 16 (twitter:description) · line 26 (JSON-LD description).

### 판정 2 — hero lede 갱신 (채택 · 문안 조정)

**최종 문안:**
```
부동산·취득세·중개수수료부터 출생신고·임대차 만료·상속포기 등 기한이 중요한 D-day 계산기까지 —
검색해도 애매한 계산을 관계·상황·조건별로 바로 확인할 수 있게 정리했습니다.
```

조정 근거:
- 달리 안이 D-day 카테고리 확장은 잘 반영했으나, 현행 lede의 "**관계·상황·조건별로**" 문구(사용자 맞춤성 어필)가 빠짐. 이 문구는 유지 가치가 큼 → 조합.
- 반영 위치: `index.html` line 210 (`<p class="lede">`).

### 판정 3 — 구 유틸 카드 색상 팔레트 정합 (예약 등록 승인)

- AdSense 심사관은 카드별 색상 일관성보다 콘텐츠 실질·기술 조건을 우선. 현재 브랜드 네이비·다크그린·스틸블루 등도 "카오스"가 아니라 카테고리별 색 구분으로 읽힐 여지.
